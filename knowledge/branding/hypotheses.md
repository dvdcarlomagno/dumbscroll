# Branding hypotheses

- A face reads as "this is about you zoning out", which fits the product better than an eye ("being watched").
- A black face on the yellow squircle stays legible in both light and dark Chrome toolbars.
- ~~Small rotations read as playful without hurting legibility.~~ Contradicted: the user called it gimmicky.
- (Demoted from rule, 2026-09-30) The Nodera CRM card system (warm grey canvas, white cards, one dark card, black/yellow/red, pills). The user said they did not like that UI at all, so it no longer applies by default.
- Another skin will not fix the popup; the user wants the experience itself to change. Supported once: the user picked Coach, a UX-led direction.
- A calm, kind tone (sentences, no red scolding) fits the user better than a gamified or dashboard tone. This is the second signal, after "too gimmicky".
