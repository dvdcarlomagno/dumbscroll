# Overlay mode hypotheses

- Users who pick fade may want a slightly see-through cap at 0 posts so the feed stays readable; current fade starts fully opaque (`opacity = 1` at 0).
- A later toggle to invert fade (more posts → more opaque) may be requested if people confuse remaining-budget with blockage.
- Overlay mode is unlikely to need the 50% usage lock applied to daily max.
